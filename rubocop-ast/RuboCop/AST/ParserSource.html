      Overview

      Loads the part of the parser gem that every parser engine needs: the node base class, the source layer (buffers, ranges, comments, source maps, the tree rewriter) and the diagnostics.

      They come from the gem when it is installed, because its parsers and builders create objects of the very same classes. Without the gem, a copy of those files that ships with this gem is loaded instead, which is all that the prism parser engine needs.

def self.ensure_parser_gem(parser_engine)
  return unless vendored?

  raise LoadError, "The `#{parser_engine}` parser engine needs the `parser` gem. Add it " \
                   'to your Gemfile, or use the `prism` parser engine, which supports ' \
                   'target Ruby versions 3.3 and above.'
end
