      • INVALID_CHARS =

        CLIENT SETINFO values must be printable ASCII with no spaces — the server rejects anything else, and redis-client swallows that error, which would silently leave lib-name empty. Parentheses are excluded as well: they delimit the suffix in lib-name=redis-rb(<suffix>), so a suffix containing them would corrupt the reported name.

        /(?:[^!-~]|[()])+/
