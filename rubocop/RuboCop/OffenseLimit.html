      Overview

      Caps how many offenses each cop gets to report.

      Counted across a whole run rather than per file, since a cop that fires a handful of times in every file is exactly the one worth capping. Offenses have to be offered in a stable order (files in the order they are reported) for the same ones to survive every time.

def elided_per_cop
  @offered.filter_map { |cop, count| [cop, count - @max] if count > @max }.sort.to_h
end

def filter(offenses)
  offenses.select { |offense| (@offered[offense.cop_name] += 1) <= @max }
end
