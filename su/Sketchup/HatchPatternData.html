      Class: Sketchup::HatchPatternData

      Relationships
      Inherits: Object

      Overview

      A HatchPatternData object holds the appearance settings of a hatch pattern detached from any named HatchPattern in the model. It is used to read and write the default section fill style stored in RenderingOptions#hatch_pattern.

      The object returned by RenderingOptions#hatch_pattern is frozen, since it is a snapshot detached from the model. Mutate a #dup of it (or a new instance) and assign it back to apply a change.

      Examples:

      model = Sketchup.active_model
data = model.rendering_options.hatch_pattern.dup
data.rotation_angle = 45.0
model.rendering_options.hatch_pattern = data

      #set_fill_pattern_from_file(file_name) ⇒ HatchPatternData
