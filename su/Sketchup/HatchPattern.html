      #save_fill_pattern_to_file(file_name) ⇒ HatchPattern

      The #save_fill_pattern_to_file method writes the .pat line-pattern definition to a file. This writes only the pattern definition, not the whole hatch pattern; use #write for the latter.

      Examples:

      hatch_pattern = Sketchup.active_model.hatch_patterns['Pattern']
hatch_pattern.save_fill_pattern_to_file('C:/patterns/ansi31.pat')

      Parameters:

      • file_name (String) —

        the path to write the .pat file to.

      Raises:

      • (ArgumentError) —

        if the pattern has no .pat definition or the file could not be written.

      Version:

      • SketchUp 2027.0

      #set_uv_scale(u_scale, v_scale) ⇒ HatchPattern

      The #set_uv_scale method sets the UV scale of the HatchPattern. Both values must be positive. The scale is a factor applied to the pattern's repeat; it is not a percentage.

      Examples:

      model = Sketchup.active_model
hatch_pattern = model.hatch_patterns['Pattern']
hatch_pattern.set_uv_scale(12.0, 12.0)

      Parameters:

      • u_scale (Float)
      • v_scale (Float)

      Raises:

        if either scale is not a positive value.
