      Overview

      Class for wrapping options that could be sensitive.

      Sensitive values are redacted in inspect, to_s, pretty printed, JSON, YAML and Marshal output. The stored values are unchanged. Deserializing a YAML or Marshal representation that contained sensitive values raises ArgumentError instead of creating an object with marker credentials.

      Since:

      • 2.1.0

      Constant Summary

      • SENSITIVE_OPTIONS =

        The options whose values will be redacted. The username is included because it is part of the userinfo segment, whose components the connection string specification treats as sensitive values.

        The arguments of the sensitive ::Mongo::URI options are redacted as a whole: authMechanismProperties may carry a credential in any of its properties (for example an AWS session token), and the driver cannot know which properties a future mechanism will treat as secret.

def reject!
  if block_given?
    n_keys = keys.size
    keys.each do |key|
      delete(key) if yield(key, self[key])
    end
    (n_keys == keys.size) ? nil : self
  else
    to_enum
  end
end

def select!
  if block_given?
    n_keys = keys.size
    keys.each do |key|
      delete(key) unless yield(key, self[key])
    end
    (n_keys == keys.size) ? nil : self
  else
    to_enum
  end
end
