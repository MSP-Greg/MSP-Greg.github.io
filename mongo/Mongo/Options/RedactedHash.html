      Overview

      A plain Hash whose string and serialized representations redact sensitive values.

      Unlike Redacted, which is a BSON::Document and normalizes its keys to strings, this class preserves the keys exactly as they were inserted. It is used for option hashes whose key types are part of the driver's observable behavior. Accessing the hash returns the real values; deserializing a representation with sensitive values raises ArgumentError.
